HFO Detector

Automatic HFO detection as in HFOApp: EDF in, HFOApp's two text files out for each frequency band. LabChart and Neuralynx recordings are first converted to EDF, with their comments in a table.

🔒 Recordings are processed on this computer. They are never uploaded.

This page was opened as a file. Browsers do not allow it to run the analysis that way: open it from its web address instead (for a local copy: python3 web/build.py --serve, then http://localhost:8000).
